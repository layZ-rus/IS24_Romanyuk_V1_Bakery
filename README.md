## 🎯 азначение и ключевой функционал

Система автоматизирует полный цикл движения хлебобулочной продукции на предприятии:
* **Сбор заявок:** приём и фильтрация заявок от торговых точек (`SHOP-xx`).
* **лгоритм планирования (MRP):** автоматический расчёт сменного производственного задания с учётом коэффициента страхового запаса, расчёт количества транспортных лотков и разузлование рецептур с проверкой дефицита сырья (`RAW-xx`) на складе.
* **обильный учёт в цехе и экспедиции:** сканирование штрихкодов лотков камерой смартфона при приёме из пекарного цеха, отгрузке по накладным и фиксации возвратов.
* **тчётность:** генерация сводного отчёта за период в формате Microsoft Excel (`.xlsx`).
* **езопасность и обезличивание:** используются исключительно синтетические обезличенные данные (`PRD-xxx`, `RAW-xx`, `SHOP-xx`), пароли хранятся в хешированном виде (`BCrypt`).

## 🛠 Стек технологий

* **Backend (`/src`):** C# (.NET 8), ASP.NET Core Web API, Entity Framework Core, Swagger / OpenAPI, ClosedXML (экспорт в `.xlsx`).
* **аза данных (`/data`):** SQLite (6 нормализованных таблиц в 3).
* **Mobile (`/mobile`):** Android Studio, Kotlin, Retrofit2, Gson, ZXing (сканер штрихкодов).
* **Тестирование (`/tests`):** xUnit, Coverlet (покрытие кода ≥ 70%).

## 🚀 ыстрый старт (апуск проекта)

### 1. апуск серверного модуля (C# API)
```bash
cd src/BakeryApi
dotnet restore
dotnet run
```
осле запуска документация **Swagger UI** будет доступна по адресу: `http://localhost:5000/swagger`

### 2. апуск мобильного клиента (Android Studio)
1. ткройте папку `/mobile` в **Android Studio**.
2.  файле конфигурации API укажите адрес сервера (`http://10.0.2` для эмулятора).
3. Соберите и запустите проект (`Shift + F10`).
